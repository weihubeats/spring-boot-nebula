# All-in-One `spring-boot-nebula-all`

Pulls in all the commonly used modules (web + mybatis + distribute-lock + excel + dynamic-datasource) with a single dependency — ideal for quickly bootstrapping a new project:

```xml
<dependency>
    <groupId>io.github.weihubeats</groupId>
    <artifactId>spring-boot-nebula-all</artifactId>
    <version>3.0.6</version>
</dependency>
```

> Recommended to split into individual modules once the project settles — it keeps dependencies clearer.
